# G-19 Dawwarha

Dawwarha (دَوَّرها) is a graduation project for the NTI MEAN Stack track.

## Project Overview

This repository contains the backend architecture for the Dawwarha platform, including the folder structure for models, routes, controllers, services, middleware, validators, utilities, and seed files.

## Backend Structure

```text
backend/
├── src/
│   ├── config/
│   ├── models/
│   ├── routes/
│   ├── controllers/
│   ├── services/
│   ├── middleware/
│   ├── validators/
│   ├── utils/
│   ├── seed/
│   └── app.js
│
├── tests/
│   ├── unit/
│   └── integration/
│
├── server.js
├── .env.example
├── .gitignore
├── package.json
└── README.md
```

## Stack

- Node.js
- Express.js
- MongoDB
- Mongoose

## Status

The current phase focuses on creating the backend architecture and keeping implementation intentionally empty.

## Notes

This project is currently in the architecture/setup stage and does not yet include business logic or runtime implementation.
