Angular HTTP Interceptor & Security Architecture

Complete client-side lifecycle implementation contract for DawwarhaAuthInterceptor

RFC 6750 Bearer Angular v18.x
01. REQUEST PIPELINE flight_takeoff

Reads accessToken from localStorage. If non-expired, clones outgoing HttpHeaders with Authorization: Bearer <token>.

• Pass-through on public auth routes
02. 401 UNAUTHORIZED history_toggle_off

Catches expired or invalid token response. Silently clears token storage, encodes active route as returnUrl, triggers session alert, and navigates to /auth/login.

• Zero infinite redirect loops
03. 403 FORBIDDEN block

Distinguishes between Suspended accounts (SUSPENDED_403) and Role authorization failures. Preserves active session tokens to avoid unnecessary re-authentications.

• Preserves user audit credentials
04. CLIENT PURGE delete_forever

Stateless design eliminates costly DB token blacklist lookups. On logout, memory store & storage tokens are synchronously annihilated; pending requests are cancelled via RxJS teardown.

• Instant, offline-resilient logout
